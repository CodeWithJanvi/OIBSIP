## 🔍 Project Details

### 1️⃣ Task 1: Landing Page | ☕ Lusso Cafe

**Objective:** Build a visually polished landing page for a brand of my choice.

A warm, elegant single-page website for a cafe, with sticky navigation, a hero section with call-to-action buttons, menu categories, filterable menu, best sellers carousel, gallery, reviews, FAQ, a table reservation form and a floating chatbot.

- ✅ Sticky navigation bar with smooth-scroll links
- ✅ Hero section with headline and call-to-action buttons
- ✅ Multiple content sections (Our Story, Menu, Gallery, Reviews and more)
- ✅ Footer with contact and social links
- ✅ Consistent colour palette and clean typography
- ✅ Responsive layout for laptop, tablet and mobile

🔗 [Live Demo](https://lusso-cafe.vercel.app/) · 📁 [Project Folder](./OIBSIP-WebDev-L1-Landing%20Page)

---

### 2️⃣ Task 2: Personal Portfolio | 💻 CodeWithJanvi

**Objective:** Create a personal portfolio website that showcases my skills, projects and contact information.

A developer-style portfolio with a boot screen, typing animation, code editor card, animated skill bars, services, journey timeline, project cards, working contact form, scroll progress ring and a terminal-style footer. It has both **dark and light themes**.

- ✅ Hero section with name, role and photo
- ✅ About Me and Skills sections
- ✅ Projects section with GitHub links
- ✅ Contact section with email, GitHub, LinkedIn and Instagram
- ✅ Smooth-scroll navigation and consistent branding
- ✅ Fully responsive (desktop, tablet and mobile)

🔗 [Live Demo](https://personalporfoliowebsite-six.vercel.app/) · 📁 [Project Folder](./OIBSIP-WebDev-L1-PersonalPortfolio)

---

### 3️⃣ Task 3: Temperature Converter | 🌡️ Thermo

**Objective:** Build an interactive tool that converts temperature between Celsius, Fahrenheit and Kelvin, with real-time input validation.

A fast converter with an animated thermometer, temperature categories, recent conversions history, click-to-copy results, a loader screen and **dark and light themes**.

- ✅ Numeric input with validation (non-numeric input shows an error message)
- ✅ Unit selector for Celsius, Fahrenheit and Kelvin
- ✅ Convert button (plus Enter key) and all three results shown at once
- ✅ Absolute zero check with a friendly message
- ✅ Clean, centred UI with clear labels

🔗 [Live Demo](https://temperatureconverter-sigma.vercel.app/) · 📁 [Project Folder](./OIBSIP-WebDev-L1-Temperature%20Converter)

## 🚀 How to Run Any Project

No installation or build step is needed.

1. **Clone the repository**
   ```bash
   git clone https://github.com/CodeWithJanvi/OIBSIP.git
   ```
2. **Open a project folder**
   ```bash
   cd "OIBSIP/OIBSIP-WebDev-L1-Landing Page"
   ```
3. **Run it**
   Double click `index.html` or open it with **Live Server** in VS Code.
